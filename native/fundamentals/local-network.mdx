While you are developing your application, you can use the Hedera-supported networks (previewnet and testnet) to test against. You can also run your own local network, a full Hedera stack on your machine, for development without testnet rate limits, resets, or faucet dependencies.

With a local network set up, you can:

* Create and submit transactions and queries to a consensus node
* Interact with the mirror node via REST APIs
* Run integration tests in CI against a network you control

[Solo](https://solo.hiero.org/docs/) is the recommended way to run a local Hedera network. It deploys a consensus node, mirror node, block node, JSON-RPC relay, and block explorer, and it works with all Hiero SDKs.

## 1. Start a local network

Install Solo and deploy a single-node network:

```bash
npm install -g @hiero-ledger/solo@latest
solo one-shot single deploy
```

See [Local Development](/native/local-dev/index) for prerequisites, verification steps, and troubleshooting.

## 2. Configure your client

Point your client at the local consensus node and mirror node instead of a public network by building the network map explicitly.

<Warning>
Do not use the built-in local-network presets. `Client.forLocalNode()` in JavaScript and `ClientForName("local")` in Go are hardcoded to `50211` for consensus gRPC and `5600` for the mirror node, which Solo 0.63 and later do not expose. The Java SDK's `Client.forName()` only accepts `mainnet`, `testnet`, and `previewnet`, and throws `IllegalArgumentException` otherwise. Build the map yourself, as shown below.
</Warning>

On Solo 0.63 and later, a single-node deployment exposes the consensus node at `127.0.0.1:35211` with node account ID `0.0.3`, and the mirror node at `127.0.0.1:38081`. Store these in an environment or config file rather than hard-coding them; they are inlined below only for readability.

<CodeGroup>

```java Java
//Create your local client
Map<String, AccountId> network = new HashMap<>();
network.put("127.0.0.1:35211", AccountId.fromString("0.0.3"));

Client client = Client.forNetwork(network);
client.setMirrorNetwork(List.of("127.0.0.1:38081"));
```


```javascript JavaScript
//Create your local client
const network = { "127.0.0.1:35211": AccountId.fromString("0.0.3") };
const mirrorNetwork = "127.0.0.1:38081";

const client = Client.fromConfig({
    network,
    mirrorNetwork,
    // Required: the SDK's address-book refresh otherwise pulls in the
    // hardcoded 50211/50212 ports, which Solo 0.63+ does not expose.
    scheduleNetworkUpdate: false,
});
```


```go Go
//Create your local client
network := make(map[string]hiero.AccountID, 1)
network["127.0.0.1:35211"] = hiero.AccountID{Account: 3}

client, err := hiero.ClientForNetworkV2(network)
if err != nil {
	panic(err)
}
client.SetMirrorNetwork([]string{"127.0.0.1:38081"})
```

</CodeGroup>

<Info>
These ports are Solo's defaults, not guarantees. Solo forwards to the next free port if one is taken, and the values changed in 0.63. Confirm what your deployment exposes with `solo deployment config ports --deployment <deployment-name>`, and see [Using Solo with Hiero SDKs](https://solo.hiero.org/docs/using-solo/using-solo-with-hiero-sdks/) for the full per-SDK walkthrough.
</Info>

## 3. Set your transaction fee paying account

You need an account ID and key to pay the [fees](/networks/fees) for each transaction and query submitted to your local network. Solo provisions a bootstrap operator account, `0.0.2`, at genesis and writes it to `systemAccounts[0]` in `~/.solo/one-shot-<deployment-name>/accounts.json`. Its key is Ed25519 in DER format. Read the `privateKey` value, the longer string beginning with `302e`, not `publicKey`.

| **Account ID**  | `0.0.2`                                                                                            |
| --------------- | -------------------------------------------------------------------------------------------------- |
| **Private Key** | `302e020100300506032b65700422042091132178e72057a1d7528025956fe39b0b847f200ab59b2fdd367017f3087137` |

<Danger>
**Note**: It is not good practice to post your private keys in any public place. These keys are provided only for development and testing purposes only. They do not exist on any production networks.
</Danger>

<CodeGroup>

```java Java wrap
client.setOperator(AccountId.fromString("0.0.2"), PrivateKey.fromString("302e020100300506032b65700422042091132178e72057a1d7528025956fe39b0b847f200ab59b2fdd367017f3087137"));
```


```javascript JavaScript wrap
client.setOperator(AccountId.fromString("0.0.2"),PrivateKey.fromString("302e020100300506032b65700422042091132178e72057a1d7528025956fe39b0b847f200ab59b2fdd367017f3087137"));
```


```go Go wrap
accountId, err := hiero.AccountIDFromString("0.0.2")
privateKey, err := hiero.PrivateKeyFromStringDer(
"302e020100300506032b65700422042091132178e72057a1d7528025956fe39b0b847f200ab59b2fdd367017f3087137")

client.SetOperator(accountId, privateKey)
```

</CodeGroup>

## 4. Submit your transaction

Submit a transaction that will create a new account in your local network. The console should print out the new account ID. In this example, we are using the same key as the transaction fee paying account as the key for the new account. You can also create a [new key](/native/keys/generate-key-pair) if you wish.

<CodeGroup>

```java Java
//Submit a transaction to your local network
TransactionResponse newAccount = new AccountCreateTransaction()
        .setKeyWithoutAlias(PrivateKey.fromString("302e020100300506032b65700422042091132178e72057a1d7528025956fe39b0b847f200ab59b2fdd367017f3087137"))
        .setInitialBalance(new Hbar(1))
        .execute(client);
                
//Get the receipt
TransactionReceipt receipt = newAccount.getReceipt(client);
        
//Get the account ID
AccountId newAccountId = receipt.accountId;
System.out.println(newAccountId);
```


```javascript JavaScript

        .execute(client);

//Get receipt

//Get the account ID

```


```go Go

```

## 5. View your transaction

You can view the executed transaction by querying your local mirror node.

The local mirror node REST endpoint is `http://localhost:38081/`.

You can view the transactions that were submitted to your local network by submitting this request:

```http
http://localhost:38081/api/v1/transactions
```

The list of supported mirror node REST APIs can be found [here](/reference/rest-api). You can also browse the same data in the Mirror Node Explorer at `http://localhost:38080/localnet/dashboard`. You have now set up your local environment. Check out the following links for more examples.

```go Go
package main

import (
	"fmt"

	hiero "github.com/hiero-ledger/hiero-sdk-go/v2/sdk"
)

func main() {
	//Create your local client
	network := make(map[string]hiero.AccountID, 1)
	network["127.0.0.1:35211"] = hiero.AccountID{Account: 3}

	client, err := hiero.ClientForNetworkV2(network)
	if err != nil {
		panic(err)
	}
	client.SetMirrorNetwork([]string{"127.0.0.1:38081"})

	//Set the transaction fee paying account
	accountId, err := hiero.AccountIDFromString("0.0.2")
	privateKey, err := hiero.PrivateKeyFromStringDer("302e020100300506032b65700422042091132178e72057a1d7528025956fe39b0b847f200ab59b2fdd367017f3087137")
	client.SetOperator(accountId, privateKey)

	//Submit a transaction to your local network
	newAccount, err := hiero.NewAccountCreateTransaction().
		SetKeyWithoutAlias(privateKey).
    		SetInitialBalance(hiero.NewHbar(1)).
		Execute(client)

	if err != nil {
		println(err.Error(), ": error getting balance")
		return
	}

	//Get receipt
	receipt, err := newAccount.GetReceipt(client)

	//Get the account ID
	newAccountId := receipt.AccountID
	fmt.Print(newAccountId)
}
```
