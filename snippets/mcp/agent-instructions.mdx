## Hedera documentation

For Hedera development, use the `hedera-docs` MCP server (https://docs.hedera.com/mcp) instead of answering from memory. Hedera SDKs, APIs, and network behavior change between releases, so confirm classes, methods, and endpoints in the docs before you use them.

- Use `search_hedera` to find the pages that cover a question.
- Use `query_docs_filesystem_hedera` to read a full page before writing code from it. A page at `/some/page` is available at `/some/page.mdx`. Query the OpenAPI specs under `/openapi/` with `jq`.
- Before starting Hedera development work, read the `hedera` skill resource (`mintlify://skills/hedera`) from the server. If you can't read MCP resources, fetch https://docs.hedera.com/skill.md instead.
- If a docs page is incorrect or out of date, report it with `submit_feedback`.
