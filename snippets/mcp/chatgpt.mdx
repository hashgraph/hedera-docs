1. Go to [ChatGPT Plugins](https://chatgpt.com/plugins), select the **"+"** button, then select **Add custom MCP server**.
2. Enter the name `Hedera Docs` and the description `Search the official Hedera documentation.`, then enter the server URL `https://docs.hedera.com/mcp`.
3. The Hedera docs server is public and needs no authentication. Review the risk warning and select **I understand and want to continue**.
4. Select **Create as a plugin** and confirm the discovered tools match the [Hedera Docs tools](/learn/getting-started/mcp-setup#available-tools). Then install the plugin.

**Verify:** Start a new conversation, type `@` in the prompt box, and select **Hedera Docs**.
