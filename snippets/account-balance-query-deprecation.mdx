`AccountBalanceQuery` no longer works. It read the consensus node's `cryptoGetBalance` query, which [consensus node release v0.77](/networks/release-notes/services) removed (testnet on September 15, 2026, mainnet on September 29, 2026). Current SDKs (JavaScript v2.89.0+, Java v2.78.0+, Go v2.85.1+) fail the call immediately with a deprecation error and never contact a node. Older SDK versions, and the Rust SDK, still send the query, and the network answers `BUSY` until the SDK runs out of retries.
