title: "Hiero Improvement Proposal (HIP)"
description: "Propose a new feature or standard for Hedera by submitting a Hiero Improvement Proposal: fork the repo, complete the HIP template, and open a pull request."
---


Do you have a new feature request for consensus or mirror nodes? Are you looking to submit a standard or informational guide for the Hedera ecosystem? Submit a Hiero Improvement Proposal (HIP). HIP editors and the community review each proposal, and the Hiero Technical Steering Committee (TSC) approves HIPs that change the Hiero codebase, as described in [HIP-1](https://hips.hedera.com/hip/hip-1). These improvement proposals can range from core protocol changes to the applications, frameworks, and protocols built on the Hedera public network and used by the community. To view all active and pending HIPs, check out the [HIP website](https://hips.hedera.com/).

1. Fork the `hiero-improvement-proposals` repository [here](https://github.com/hiero-ledger/hiero-improvement-proposals).
2. Fill out this [HIP template](https://github.com/hiero-ledger/hiero-improvement-proposals/blob/main/hip-0000-template.md).
3. Create a pull request against `hiero-ledger/hiero-improvement-proposals` main branch.

<Info>
**Note:** Which category should you make the **HIPs**? See [HIP-1](https://github.com/hiero-ledger/hiero-improvement-proposals/blob/main/HIP/hip-1.md) for details on the **HIP** process, or watch the following video tutorial.
</Info>
