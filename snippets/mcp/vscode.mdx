Create or edit `~/.copilot/mcp-config.json` (or `$COPILOT_HOME/mcp-config.json` if you set `COPILOT_HOME`) and add the following:

```json
{
  "mcpServers": {
    "hedera-docs": {
      "type": "http",
      "url": "https://docs.hedera.com/mcp"
    }
  }
}
```

**Verify:** In the Chat view, send a prompt that names the server, such as *"Use the hedera-docs MCP server to find how to create a topic on Hedera."* Expand the tool call in the response and confirm it came from `hedera-docs`. See VS Code's [Verify the first tool call](https://code.visualstudio.com/docs/agent-customization/mcp-servers#_verify-the-first-tool-call) for the full checks.
