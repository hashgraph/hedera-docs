`AccountBalanceQuery` reads the consensus node's `cryptoGetBalance` query. Its throttle has been reduced in stages since consensus node release v0.74, and the query is scheduled for removal on mainnet with **consensus node release v0.77**. Check the [consensus node release notes](/networks/release-notes/services) for where v0.77 has been deployed. After removal, `AccountBalanceQuery` will no longer function.
