Add the following to `~/.cursor/mcp.json` (all projects) or `.cursor/mcp.json` in your project root (one project):

```json
{
  "mcpServers": {
    "hedera-docs": {
      "url": "https://docs.hedera.com/mcp"
    }
  }
}
```

**Verify:** Open **Customize** in the Cursor sidebar and confirm `hedera-docs` is enabled. Then, in Cursor's chat, ask *"What tools do you have available?"* and confirm the response lists the [Hedera Docs tools](/learn/getting-started/mcp-setup#available-tools).
