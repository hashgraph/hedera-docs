[Hedera AI Studio](https://hedera.com/ai-studio) provides open source tools for AI agents and agentic commerce. It includes the [Hedera Agent Kit](/solutions/ai/agent-kit/index), [Agent Lab](/solutions/ai/agent-lab), [Agent Builder](https://portal.hedera.com/agent-lab#build), the [Network MCP Server](/solutions/ai/hosted-mcp-server), and support for [x402](/solutions/ai/x402/index) payments on Hedera. Build AI agents that run transparently and verifiably on the Hedera network, use Hedera Consensus Service (HCS), Hedera Token Service (HTS), and other network services, and transact through natural language.

## Get started

Use the Agent Kit to build agents that interact with the Hedera network, query Hedera mirror nodes, and use native Hedera services.

* [**Try the 60-second quickstart**](/solutions/ai/agent-kit/js/quickstart). Use `npm` to install the latest version of the Agent Kit and create a simple "Hello Hedera Agent Kit" agent, or follow the [Python quickstart](/solutions/ai/agent-kit/python/quickstart).
* Clone the Agent Kit repository and [**try different examples**](https://github.com/hashgraph/hedera-agent-kit/blob/main/docs/DEVEXAMPLES.md):
  * The **example tool-calling agent** carries out simple tasks with Hedera tools in autonomous mode.
  * The **structured chat agent** works like the tool-calling agent, with prebuilt LangChain Hub prompts (LangChain v0.3 only).
  * The **human-in-the-loop agent** shows how to create a more controlled workflow.
  * **Try the local MCP server** to interact with Hedera from an application such as Claude Desktop or an IDE such as Cursor.
  * Create **hooks and policies** to put guardrails on agent behavior.

To connect an AI client instead, follow the [Network MCP Server quickstart](/solutions/ai/hosted-mcp-server#claude-cli-quickstart). For agent payments, see [Pay with x402](/solutions/ai/x402/pay-with-x402) and [Accept x402](/solutions/ai/x402/merchant-integration).
