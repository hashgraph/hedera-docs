## Chainlink CCIP on Hedera

The **Chainlink Cross-Chain Interoperability Protocol (CCIP)** is a standard for blockchain interoperability that enables developers to build **secure cross-chain applications** capable of transferring tokens, sending messages, and executing actions across multiple blockchains.

Through the **Cross-Chain Token (CCT)** standard, CCIP allows token developers to integrate new or existing tokens in a **self-serve** way, without vendor lock-in or restrictive dependencies.

**CCTs support:**

- Self-serve deployments with full control and ownership
- Zero-slippage transfers across supported chains
- Enhanced programmability via configurable rate limits
- Smart Execution for reliable cross-chain delivery

CCIP is powered by **Chainlink Decentralized Oracle Networks (DONs)**.

## CCIP Availability on Hedera

CCIP is live on both **Hedera Mainnet** and **Hedera Testnet**.

| Network            | Chain ID | CCIP Directory                                                                                   |
| ------------------ | -------- | ------------------------------------------------------------------------------------------------ |
| **Hedera Mainnet** | `295`    | [Hedera Mainnet on the CCIP Directory](https://docs.chain.link/ccip/directory/mainnet/chain/hedera-mainnet) |
| **Hedera Testnet** | `296`    | [Hedera Testnet on the CCIP Directory](https://docs.chain.link/ccip/directory/testnet/chain/hedera-testnet) |

On Hedera Mainnet, CCIP lanes connect Hedera to chains including Ethereum, Arbitrum, Base, Optimism, Avalanche, Polygon, and Solana. On Hedera Testnet, lanes connect to the matching test networks, such as Ethereum Sepolia.

<Info>
  The Chainlink CCIP Directory is the source of truth for supported lanes, supported tokens, rate limits, and contract addresses. Lanes and tokens are added over time, so check the directory before you deploy.
</Info>

## Overview of CCIP and HTS Compatibility

On Hedera, CCIP extends interoperability between **Hedera** and other blockchains such as Ethereum.
It works with both the **Hedera Token Service (HTS)** and standard **EVM tokens (ERC-20 and ERC-721)**, enabling developers to move tokens, data, and logic across ecosystems.

With CCIP, developers can:

- Send and receive arbitrary messages between chains
- Execute programmable cross-chain logic via Chainlink's oracle network
- Transfer tokens across chains using the **Cross-Chain Token (CCT)** standard
- Pay fees on Hedera with **LINK** or **Wrapped HBAR (WHBAR)**

### Setup

1. **Install dependencies**

   ```bash
   pnpm install
   ```

2. **Configure your environment**

   ```bash
   cp .env.example .env
   ```

   Add your Hedera Testnet private key:

   ```
   PRIVATE_KEY=0x...
   ```

3. **Run a demo**

   ```bash
   pnpm run demo:hedera-sepolia-link
   ```

  ```bash
  pnpm run wrap-hbar
  ```

## Developer Considerations

### Decimal Precision

HBAR's smallest unit is the **tinybar (8 decimals)**.
Since CCIP on EVM networks operates with **18-decimal precision**, conversions between tinybars and wei-based values may be required.
See [Understanding Hedera's EVM Differences and Compatibility](/evm/differences).

### Cross-Chain Fees

Make sure your wallet holds enough of a supported fee token on the source chain to cover CCIP fees. On Hedera, that is **LINK** or **WHBAR**. The demos pay fees from Ethereum Sepolia in **ETH**.

### Message Timing

Cross-chain message delivery can take several minutes while the Chainlink oracle network waits for source-chain finality and executes the message on the destination chain.

## Summary

**Chainlink CCIP** is a standard for **secure, decentralized cross-chain interoperability**, and it is live on Hedera Mainnet and Hedera Testnet.
It connects Hedera to a broader multi-chain ecosystem, letting assets, logic, and state move across blockchains through a single protocol.

On Hedera, CCIP supports **HTS and EVM tokens** under the **CCT standard**.
It complements other interoperability solutions such as [**LayerZero**](/evm/integrations/cross-chain/layerzero) and **Hashport**.
